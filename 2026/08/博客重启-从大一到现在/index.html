博客重启

这个博客是大一的时候搭的，用 Hexo 写了没几篇就荒废了——源码丢了，只剩生成后的页面躺在 GitHub Pages 上。今天把它重新捡起来，从零重建。

为什么重启

因为要开始工作了。即将入职海康威视数字化部门，做 IT 运维工程师（基础架构方向）。做运维这行，最值钱的资产就是积累：

  • 处理过的故障
  • 踩过的坑
  • 学到的命令和工具
  • 沉淀下来的方法论

如果不记录，这些东西就随着时间蒸发了。这个博客，就是我的积累仓库 + 对外窗口。
