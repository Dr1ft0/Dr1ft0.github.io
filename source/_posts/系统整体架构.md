> 本文档描述新系统（.NET 8 Web API + Vue 3 SPA）的整体架构、分层职责、核心链路与各框架的可视化关系。

## 〇、脱敏声明

本文档**不包含**任何真实的生产敏感信息。以下内容一律使用占位符表示：

| 占位符 | 含义 |
|--------|------|
| `<DB_HOST>` | 数据库服务器地址 |
| `<DB_NAME>` | 数据库实例名 |

## 一、系统定位

企业内部的**文件共享管理平台**：管理员通过 Web 界面登记、授权、管理文件服务器上的共享文件夹（增删改查 + 续期 + 日志）。

### 新旧系统核心差异

| 维度 | 旧系统 | 新系统 |
|------|--------|--------|
| 技术栈 | ASP.NET Web Forms (.NET Framework 4.5) | .NET 8 Web API + Vue 3 SPA |
| 核心逻辑 | 全部编译在 DLL 中，**无源码** | 完全开源、分层清晰 |
| 与文件服务器联动 | **无**，只写数据库 | **有**，SSH 远程执行共享命令 |
| 共享生效方式 | 人工上文件服务器跑脚本 | **点击即共享**，全自动 |
| 前端交互 | HTML + jQuery + AJAX（整页/半页刷新） | SPA 单页应用、组件化 |

### 6.2 状态机与补偿

```mermaid
stateDiagram-v2
    [*] --> Validate
    Validate --> CreateOnServer : 参数合法
    Validate --> [*] : 抛 BusinessException
    CreateOnServer --> WriteDb : SSH 执行成功
    CreateOnServer --> [*] : SSH 失败 / 目录已存在
```

### 8.2 命令白名单

| 操作 | 命令模板 |
|------|----------|
| 建目录 | `mkdir "<LocalPath>"` |

| 删共享 | `net share "<Name>" /delete` |
| 删目录 | `rmdir /s /q "<LocalPath>"` |
| 设权限 | `icacls "<LocalPath>" /grant "<Account>:(OI)(CI)<M 或 R>"` |
| 重置权限 | `icacls "<LocalPath>" /reset` |
| 查共享 | `net share` |

> 生产环境建议：敏感项（连接串、JWT 密钥、DES 密钥）改由**环境变量或密钥管理服务**注入，不落明文配置文件。
